# Vox İşitme Web Sitesi

Vox İşitme Cihazları için hazırlanmış, mobil uyumlu tek sayfalık kurumsal web sitesi.

## Kullanım

Projeyi indirdikten sonra `index.html` dosyasını bir tarayıcıda açmanız yeterlidir.

## İçerik

- Ana sayfa ve iletişim bölümleri
- İşitme hizmetleri tanıtımı
- Mobil uyumlu tasarım
- Şeffaf favicon ve özgün hero görseli
